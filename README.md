## 🚀 Featured Projects

### 1. WWW 2025 MM-CTR Challenge — Multimodal Click-Through Rate Prediction
[**View repository →**](https://github.com/AbdelilahElgallati/WWW-2025-MM-CTR-Challenge-Task-1-2-Solution)

Developed a multimodal pipeline for short-video recommendation CTR prediction, combining image/text representations with user and item features.

- Processed **3.6 million training samples**.
- Used **CLIP** image/text embeddings and projected fused representations from 512D to 128D.
- Combined categorical embeddings, a Transformer, a Deep Cross Network, and a DNN.
- Reported **0.9495 validation AUC** in the documented experiment setup.

**Stack:** Python · PyTorch · CLIP · Transformers · Deep Cross Network · GPU training

<sub>Note: the AUC is a project validation result, not a claim of production performance or online business lift.</sub>

### 2. Course Materials RAG — Multilingual Study Assistant
[**View repository →**](https://github.com/AbdelilahElgallati/Course-Materials-RAG)

Built a retrieval-augmented assistant that answers questions from course materials and returns source references.

- Supports PDF, text/Markdown, and YouTube transcript content.
- Generates multilingual embeddings and indexes chunks with FAISS.
- Uses semantic retrieval, Maximal Marginal Relevance (MMR), and course-scoped filtering.
- Provides a FastAPI backend and React/TypeScript interface.

**Stack:** Python · FastAPI · Sentence-Transformers · FAISS · Llama 3.3 · React · TypeScript

### 3. MovieRec — Adaptive Hybrid Movie Recommender
[**View repository →**](https://github.com/AbdelilahElgallati/Movie-Recommender-System-Project)

Created a movie recommendation application that adapts its recommendation strategy to the amount of feedback available for each user.

- Combines collaborative filtering, content-based similarity, and popularity ranking.
- Adjusts the weighting strategy as users submit more ratings.
- Includes a Flask API, React/TypeScript interface, MongoDB persistence, and TMDB metadata enrichment.

**Stack:** Python · Flask · scikit-learn · TF-IDF · React · TypeScript · MongoDB

### 4. Internship Aggregator — Automated Data Collection
[**View repository →**](https://github.com/AbdelilahElgallati/Internship)

Built a platform for collecting, storing, searching, and refreshing internship listings.

- Uses Scrapy for crawling and FastAPI for data access.
- Persists collected listings in Supabase.
- Schedules refreshes with APScheduler.
- Exposes search, filtering, pagination, and scrape-status endpoints.

**Stack:** Python · Scrapy · FastAPI · Supabase · APScheduler · React/Next.js
